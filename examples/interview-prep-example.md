# Interview Prep Example

## User Request

Help me prepare for a software engineering internship interview.

## Example Output

## Likely Question Areas

- Python and Java fundamentals.
- Data structures and algorithms.
- Debugging and testing habits.
- Project walkthroughs.
- Teamwork and communication.

## STAR Answer Frame

Use:

1. Situation: project context.
2. Task: your responsibility.
3. Action: what you personally did.
4. Result: outcome, learning, or measurable effect if supported.

## Project Walkthrough Prompt

Explain one project in this order:

- Problem.
- Constraints.
- Design choice.
- Implementation.
- Testing.
- What you would improve.
