# PDF Resume Example

## User Request

Can you generate a polished PDF resume based on the optimized version?

## Expected Skill Behavior

1. Check whether enough optimized resume content is already available.
2. Ask for target industry and role if missing.
3. Ask which style the user prefers:
   - `Classic Professional` for finance, consulting, law, government, education, traditional corporate, administration, accounting, and audit.
   - `Modern Minimal` for technology, data, AI, software engineering, product, business analyst, startup, and internet roles.
   - `Creative Clean` for marketing, content, media, branding, design-adjacent, and creator roles.
4. Ask whether the user wants to add a formal photo or headshot.
5. If the user wants a photo, ask them to upload a clear, formal, front-facing image.
6. Default to `Modern Minimal` if the user does not choose a style.
7. Generate a clean resume structure without unsupported claims.
8. Build a text-based PDF and verify layout quality before finalizing.

## Example Response Sketch

I can build the PDF from the optimized resume content you already provided. For a software engineering internship, I recommend `Modern Minimal` because it is clean, ATS-friendly, and suitable for tech roles.

Before generating it, please confirm:

- Target role / industry: Software Engineering Intern / Technology
- Style: Modern Minimal
- Add formal photo: no by default

I will not add unsupported metrics, skills, or experience. After generating the PDF, I will check that the file is non-empty, text is extractable, and there are no obvious layout issues. No fake download link will be used.
