# Application Email Example

## User Request

Write a concise application email for this internship.

## Example Output

Subject: Application for Software Engineering Intern Role

Dear Hiring Team,

I am applying for the Software Engineering Intern role. I am a computer science student with project experience in Python, backend tooling, and machine learning evaluation. My recent projects involved building structured data workflows, validating model performance, and documenting tradeoffs clearly.

I would welcome the opportunity to contribute to your engineering team and learn from production software practices. I have attached my resume for your review.

Best regards,  
Alex Chen

## Behavior Notes

- Keep it concise.
- Match the target role.
- Do not add unverifiable claims.
