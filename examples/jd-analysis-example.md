# JD Analysis Example

## User Request

Analyze this software engineering internship JD and tell me how well my resume fits.

## Expected Skill Behavior

1. Extract core responsibilities, required skills, preferred skills, tools, and soft skills.
2. Map the user's real resume evidence to the JD.
3. Identify missing or weak evidence.
4. Recommend honest positioning and keyword improvements.
5. Avoid inventing experience or metrics.

## Example Output Shape

```markdown
## JD Signal
- Role type: Software Engineering Intern
- Strong signals: Python, APIs, testing, Git, teamwork
- Hidden expectations: readable code, debugging discipline, basic system design

## Resume Match
- Strong: Python project work, Git, ML pipeline, structured testing
- Partial: API experience exists but should be clearer
- Missing: explicit unit tests and deployment experience

## Recommended Positioning
Position the candidate as a CS student with practical Python project experience, careful testing habits, and the ability to explain tradeoffs clearly.
```
