# Sample Prompts

## Resume Optimization

- 帮我根据这个 JD 优化简历。
- Rewrite my resume bullets for this software engineering internship.
- Score my resume against this job description.

## Application Materials

- Write a concise application email for this role.
- Draft a cover letter based on my real experience.
- Help me write a LinkedIn referral request.

## Interview Preparation

- Give me interview questions for this data analyst internship.
- Help me prepare STAR answers based on my projects.

## PDF Resume Builder

- 帮我把优化后的简历生成一份有审美的 PDF 简历。
- Can you generate a polished ATS-friendly PDF resume from this optimized resume?
- Create a modern minimal PDF resume based on the revised resume content.
- 帮我做一版适合投科技岗的英文 PDF 简历。
- 我想要带证件照的简历 PDF，可以吗？
