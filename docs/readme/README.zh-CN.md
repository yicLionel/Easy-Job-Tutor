## 🎯 它到底能帮你做什么？

### 1️⃣ 读懂招聘要求（JD 分析）
粘贴一个岗位描述进去，它能帮你拆解出：
- 这个岗位**到底要你干什么**（不只是字面意思）
- **硬技能**（必须会的技术/工具）和**软技能**（沟通、团队协作…）
- **隐性条件**——JD 没明说但 HR 心里有数的要求

### 2️⃣ 拿你的经历跟岗位匹配（差距诊断）
把你的简历发给它，它会逐条对比：
- ✅ **强证据**：你的经历正好对上这个要求
- ⚠️ **弱证据**：沾边但写得不够出彩
- ❌ **缺口**：这个要求你确实还没素材，需要补充什么

### 3️⃣ 追问你没想起来的关键素材
不会直接编造你从没做过的事，而是问你一些很具体的问题，比如：
> "你说你在社团做过宣传，具体用了什么工具？做了多少场活动？覆盖了多少人？"
> "这个课程项目的 final score 是多少？和谁合作完成的？"

有了这些细节，你的简历才有说服力。

### 4️⃣ 重写简历内容（bullet 优化）
把你原来干巴巴的描述（比如"负责公众号运营"）改成：
> 📝 **"独立运营学院官方公众号，6 个月产出 40+ 篇推文，最高单篇阅读量 3.2 万，关注数增长 1200 人。"**

### 5️⃣ 帮你写求职信、申请邮件、内推私信
- 🎯 **Cover Letter**（求职信）
- 📧 **申请邮件**（投递用）
- 💬 **LinkedIn / 微信私信**（找人内推时用）

### 6️⃣ 准备面试
把简历里每一条内容转成**面试官可能会问的问题 + 你应该怎么回答的提纲**，让你面试时不慌。

### 7️⃣ 生成漂亮的简历 PDF（可选）
如果你要最终版，它可以把优化好的内容排版成一份**专业、清晰、HR 看着舒服**的 PDF 简历。支持三种风格：

| 风格 | 适合哪些岗位 |
| :--- | :--- |
| `Classic Professional` | 金融、咨询、法律、政府、国企、教育、会计、审计 |
| `Modern Minimal` | **默认风格**——科技、数据、AI、产品、互联网、创业公司 |
| `Creative Clean` | 市场、内容、媒体、品牌、设计、新媒体运营 |

## 🔧 安装到你的 AI（一行命令）

你需要一个支持 Skill 的 AI 助手（比如 Claude Code、Codex CLI、OpenCode 或 Hermes Agent），然后把 Easy-Job-Tutor 装进去。

> 🖥️ **如果你不懂命令行（终端），可以把这些步骤复制给你的程序员朋友，或者在 AI 工具里问"怎么安装 Easy-Job-Tutor"——AI 会一步一步教你的。**

### 一键安装

根据你的操作系统，复制粘贴对应的一行命令即可。它会自动完成：**创建虚拟环境 → 安装依赖（含 PDF 导出）→ 检测并安装到你已装好的 AI 工具**。

**macOS / Linux**

```bash
git clone https://github.com/yicLionel/Easy-Job-Tutor.git && cd Easy-Job-Tutor && python3 install.py
```

**Windows（PowerShell）**

```powershell
git clone https://github.com/yicLionel/Easy-Job-Tutor.git; cd Easy-Job-Tutor; py install.py
```

> 💡 **可选参数**：暂时用不上 PDF 导出，加 `--skip-pdf`；不想自动装进 AI 工具，加 `--skip-tools`；脚本没检测到你的工具时，用 `--tool codex / claude / opencode / hermes` 强制指定。
> 🔔 如果依赖安装报错，不要慌——**核心功能（JD 分析、简历优化、面试准备）不需要它也能用**，PDF 导出是可选的。

> 安装完成后，你的 AI 助手就学会这项技能了！

## 🚀 快速开始

### 怎么用？—— 跟你的 AI 这样说就行：

> 💡 **两种召唤方式**：在提示词里直接说「使用 Easy-Job-Tutor」，或者如果你的 AI 工具支持斜杠命令，直接输入 `/easy-job-tutor` 也能召唤这个技能。

把你要投的**岗位描述（JD）** 和你的**现有简历**发给 AI，然后直接说：

> **"请用 Easy-Job-Tutor 帮我分析这个岗位，然后优化我的中文简历。不要编造经历，缺了什么关键信息先问我。"**

AI 就会一步步帮你做完全流程：
1. ✅ 先分析岗位要求
2. ✅ 再对照你的经历诊断差距
3. ✅ 追问你缺少的关键信息
4. ✅ 重写你的简历内容
5. ✅ （可选）帮你生成 PDF

### 想只看某一部分，也可以这样说：

| 你想做什么 | 对 AI 这样说 |
| :--- | :--- |
| 只分析岗位 | "帮我用 Easy-Job-Tutor 分析这个 JD，告诉我这个岗位到底看重什么" |
| 只改简历 | "参考这个 JD，帮我把简历上的工作经历改得更专业" |
| 写 Cover Letter | "帮我把这个岗位写一封求职信" |
| 准备面试 | "根据优化后的简历，帮我准备面试可能会问的问题" |
| 生成 PDF | "帮我把简历生成 PDF，用 Modern Minimal 风格" |

## 💬 参考用法：把真实经历交给 AI

下面的内容都是虚构示例，用来说明怎样提供材料。实际使用时请只填写自己能解释、能核实的经历；不知道的数据就写「待确认」，不要让 AI 猜测或补造。

### 例子一：没有实习，也能申请数据分析实习

把课程项目、社团经历和 JD 一起发给 AI：

```text
请用 Easy-Job-Tutor 帮我准备数据分析实习的中文简历。

目标 JD：
- 熟悉 SQL、Python、Excel，能完成数据清洗和基础分析；
- 有可视化、业务分析项目经验优先；
- 能与产品、运营协作并清晰汇报结论。

我的真实经历：
- 和 3 名同学完成校园外卖问卷分析课程项目；
- 我用 Python 清洗了 1,200 份有效问卷，并用 Excel 制作图表；
- 最终完成 12 页分析报告和课堂汇报；
- 没有做过真实 A/B 测试，也不知道报告是否被业务采用。

请先输出：JD 要求和我经历的对应表、最需要补充的 5 个问题，
再只基于已确认事实写简历 bullet。不要把课程项目写成公司实习。
```

这样得到的是能经得起追问的项目表达，而不是把「做过作业」硬包装成「有工作经验」。

### 例子二：从运营转向 AI 产品经理

转行时最重要的是分清直接经验、可迁移能力和真实缺口：

```text
我计划从运营转向 AI 产品经理，请用 Easy-Job-Tutor 先做差距诊断，不要直接写最终简历。

目标 JD：
- 负责 AI 产品需求调研、PRD、原型和上线复盘；
- 理解大模型、RAG 或 Agent 的典型使用边界；
- 能推动研发、设计和业务团队协作。

已确认经历：
- 负责过企业培训活动的需求收集、排期和跨部门沟通；
- 自学完成一个内部知识库问答 Demo，但没有上线，也没有真实用户数据；
- 写过功能说明和测试清单，没有独立负责完整 PRD。

请把内容分为「直接证据」「可迁移能力」「学习/作品证据」「真实缺口」，
并告诉我还需要补充哪些事实，才适合使用“负责”或“推动”等动词。
```

目标不是堆砌 AI 关键词，而是拿到一份诚实、可执行的补证计划。

### 例子三：同一份经历投递多个岗位

不要把产品、运营、增长的关键词混成一份万能简历。先建立同一事实底稿，再分别生成版本：

```text
请基于同一份真实经历底稿，为我生成「产品运营」和「用户增长」两个独立版本。

事实底稿：
- 在校园社团负责活动报名流程优化；
- 访谈 15 名报名者，整理出 4 个高频问题；
- 与设计同学共同修改报名表单和提醒文案；
- 活动报名人数从上一期的 86 人增长到 124 人；
- 无法确认增长完全由表单改版造成。

岗位 A：产品运营 JD：[粘贴 JD]
岗位 B：用户增长 JD：[粘贴 JD]

请先输出两个岗位的证据映射和版本差异表，再分别写简历 bullet。
不要把团队成果全部归因给我；对无法确认因果关系的数据使用审慎表述。
```

如果内容已经确认，再补充一句「请用 Modern Minimal 风格生成一页 A4 PDF，并检查内容溢出、空白页和占位符」，即可进入排版导出阶段。

## ⚠️ 重要提醒

- ✅ **不编造**：不会帮你编造学历、公司、项目经历、数据或奖项
- ✅ **先追问再写**：没有证据的内容会先问你，不会直接写进简历
- ✅ **为 HR 设计**：优先让 HR 能一眼看出你的匹配度，而不是堆砌关键词
- ✅ **诚实第一**：你的简历在面试中一定能经得起追问
