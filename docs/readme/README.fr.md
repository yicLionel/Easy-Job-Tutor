## 🎯 Que peut-il faire concrètement pour vous ?

### 1️⃣ Décrypter l'offre d'emploi (analyse du JD)
Collez une description de poste et il en extrait pour vous :
- ce que le poste **attend vraiment de vous** (au-delà du sens littéral)
- les **compétences techniques** (technologies/outils indispensables) et les **compétences relationnelles** (communication, travail d'équipe…)
- les **conditions implicites** — les exigences que le JD ne mentionne pas mais que les RH ont en tête

### 2️⃣ Confronter votre expérience au poste (diagnostic des écarts)
Envoyez-lui votre CV, il compare point par point :
- ✅ **Preuve solide** : votre expérience correspond exactement à cette exigence
- ⚠️ **Preuve faible** : c'est proche, mais ce n'est pas assez mis en valeur
- ❌ **Écart** : vous n'avez pas encore d'éléments pour cette exigence ; voici ce qu'il faut compléter

### 3️⃣ Vous demander les éléments clés que vous aviez oubliés
Il n'invente jamais ce que vous n'avez pas fait : il vous pose des questions très concrètes, par exemple :
> « Vous dites avoir fait de la communication dans une association : quels outils avez-vous utilisés exactement ? Combien d'événements avez-vous organisés ? Combien de personnes avez-vous touchées ? »
> « Quel score final avez-vous obtenu à ce projet de cours ? Avec qui l'avez-vous réalisé ? »

C'est grâce à ces détails que votre CV devient convaincant.

### 4️⃣ Réécrire le contenu du CV (optimisation des bullets)
Il transforme vos descriptions ternes (par exemple « j'étais responsable de la gestion du compte officiel ») en :
> 📝 **« J'ai géré en autonomie le compte officiel de la faculté : plus de 40 publications en 6 mois, jusqu'à 32 000 lectures pour un seul article, et 1 200 nouveaux abonnés. »**

### 5️⃣ Rédiger votre lettre de motivation, vos e-mails de candidature et vos messages de recommandation
- 🎯 **Cover Letter** (lettre de motivation)
- 📧 **E-mail de candidature** (pour postuler)
- 💬 **Message privé LinkedIn / WeChat** (pour demander une recommandation interne)

### 6️⃣ Préparer l'entretien
Il transforme chaque ligne de votre CV en **questions que le recruteur pourrait poser + un plan de réponses**, pour aborder l'entretien sans stress.

### 7️⃣ Générer un beau CV en PDF (optionnel)
Si vous voulez la version finale, il peut mettre en page vos contenus optimisés dans un CV PDF **professionnel, clair et agréable à lire pour les RH**. Trois styles sont disponibles :

| Style | Postes adaptés |
| :--- | :--- |
| `Classic Professional` | Finance, conseil, droit, fonction publique, entreprises publiques, éducation, comptabilité, audit |
| `Modern Minimal` | **Style par défaut** — tech, data, IA, produit, internet, startups |
| `Creative Clean` | Marketing, contenu, médias, marque, design, gestion des médias sociaux |

## 🔧 Installez-le dans votre IA (une seule commande)

Vous avez besoin d'un assistant IA compatible Skill (comme Claude Code, Codex CLI, OpenCode ou Hermes Agent), puis vous installez Easy-Job-Tutor dedans.

> 🖥️ **Si vous n'êtes pas à l'aise avec la ligne de commande (le terminal), copiez ces étapes à un ami développeur, ou demandez simplement dans votre outil IA « comment installer Easy-Job-Tutor » — l'IA vous guidera pas à pas.**

### Installation en une commande

Selon votre système d'exploitation, copiez-collez la commande correspondante. Tout se fait automatiquement : **création de l'environnement virtuel → installation des dépendances (y compris l'export PDF) → détection et installation dans vos outils IA déjà en place**.

**macOS / Linux**

```bash
git clone https://github.com/yicLionel/Easy-Job-Tutor.git && cd Easy-Job-Tutor && python3 install.py
```

**Windows (PowerShell)**

```powershell
git clone https://github.com/yicLionel/Easy-Job-Tutor.git; cd Easy-Job-Tutor; py install.py
```

> 💡 **Paramètres optionnels** : ajoutez `--skip-pdf` si vous n'avez pas besoin de l'export PDF pour l'instant ; ajoutez `--skip-tools` si vous ne voulez pas d'installation automatique dans vos outils IA ; si le script ne détecte pas votre outil, forcez-le avec `--tool codex / claude / opencode / hermes`.
> 🔔 Si l'installation des dépendances échoue, pas de panique — **les fonctionnalités principales (analyse JD, optimisation du CV, préparation à l'entretien) fonctionnent sans cela** ; l'export PDF reste optionnel.

> Une fois l'installation terminée, votre assistant IA maîtrise cette compétence !

## 🚀 Pour démarrer rapidement

### Comment l'utiliser ? — Dites simplement ceci à votre IA :

> 💡 **Deux façons de l'invoquer** : mentionnez « Utilise Easy-Job-Tutor » dans votre prompt, ou si votre outil IA prend en charge les commandes slash, tapez simplement `/easy-job-tutor` pour déclencher cette compétence.

Envoyez à l'IA la **description du poste (JD)** auquel vous postulez et votre **CV actuel**, puis dites-lui simplement :

> **« Utilise Easy-Job-Tutor pour analyser ce poste, puis optimise mon CV. N'invente rien et demande-moi d'abord les informations clés manquantes. »**

L'IA déroule alors tout le processus, étape par étape :
1. ✅ Analyser d'abord les exigences du poste
2. ✅ Diagnostiquer ensuite les écarts avec votre expérience
3. ✅ Vous demander les informations clés manquantes
4. ✅ Réécrire le contenu de votre CV
5. ✅ (Optionnel) Générer votre PDF

### Pour ne traiter qu'une partie précise, dites par exemple :

| Ce que vous voulez faire | Dites ceci à l'IA |
| :--- | :--- |
| Analyser uniquement le poste | « Analyse ce JD avec Easy-Job-Tutor et dis-moi ce que ce poste valorise vraiment » |
| Améliorer uniquement le CV | « En te référant à ce JD, aide-moi à rendre mon expérience professionnelle plus professionnelle sur mon CV » |
| Rédiger une Cover Letter | « Rédige une lettre de motivation pour ce poste » |
| Préparer l'entretien | « À partir de mon CV optimisé, aide-moi à préparer les questions qui pourraient être posées en entretien » |
| Générer un PDF | « Génère mon CV en PDF, en style Modern Minimal » |

## 💬 Exemples d'utilisation : confiez vos vraies expériences à l'IA

Les contenus ci-dessous sont des exemples fictifs destinés à illustrer comment fournir vos éléments. Dans la pratique, ne renseignez que des expériences que vous pouvez expliquer et vérifier ; pour les données inconnues, écrivez « à confirmer » et ne laissez pas l'IA deviner ou inventer.

### Exemple 1 : postuler à un stage en analyse de données sans stage préalable

Envoyez à l'IA vos projets de cours, vos expériences associatives et le JD :

```text
Utilise Easy-Job-Tutor pour m'aider à préparer mon CV pour un stage en analyse de données.

JD visé :
- Maîtrise de SQL, Python et Excel, capable d'effectuer du nettoyage de données et des analyses de base ;
- Une expérience de projets en visualisation ou en analyse métier est un plus ;
- Capacité à collaborer avec les équipes produit et opérations et à présenter clairement les conclusions.

Mon expérience réelle :
- Projet de cours sur l'analyse d'un questionnaire de livraison de repas sur le campus, réalisé avec 3 camarades ;
- J'ai nettoyé 1 200 questionnaires valides avec Python et créé des graphiques avec Excel ;
- Nous avons finalement produit un rapport d'analyse de 12 pages et une présentation en classe ;
- Je n'ai jamais réalisé de véritable test A/B et je ne sais pas si le rapport a été adopté par l'entreprise.

Commence par : un tableau de correspondance entre les exigences du JD et mon expérience, puis les 5 questions les plus importantes à compléter.
Ensuite seulement, rédige les bullets du CV en te basant uniquement sur des faits confirmés. Ne présente pas un projet de cours comme un stage en entreprise.
```

Vous obtenez ainsi une présentation de projet qui résiste aux questions, plutôt qu'un « devoir d'école » déguisé en « expérience professionnelle ».

### Exemple 2 : passer des opérations à chef de produit IA

En reconversion, l'essentiel est de distinguer l'expérience directe, les compétences transférables et les vrais écarts :

```text
Je prévois de passer des opérations à chef de produit IA. Utilise Easy-Job-Tutor pour faire d'abord un diagnostic des écarts, sans rédiger directement le CV final.

JD visé :
- En charge de la recherche utilisateur, du PRD, du prototypage et du bilan post-lancement pour les produits IA ;
- Comprendre les limites d'usage typiques des grands modèles de langage, du RAG ou des Agents ;
- Être capable de faire collaborer les équipes développement, design et métier.

Expériences confirmées :
- J'ai géré la collecte des besoins, la planification et la communication inter-services pour des formations en entreprise ;
- J'ai réalisé en autodidacte un démo de Q&R sur une base de connaissances interne, mais il n'a jamais été mis en ligne et je n'ai pas de données utilisateurs réelles ;
- J'ai rédigé des descriptions fonctionnelles et des listes de tests, sans avoir piloté un PRD complet de bout en bout.

Classe le contenu en « preuves directes », « compétences transférables », « preuves d'apprentissage/réalisations » et « vrais écarts »,
et indique-moi quels faits je dois encore compléter avant de pouvoir utiliser des verbes comme « être en charge de » ou « piloter ».
```

L'objectif n'est pas d'empiler des mots-clés IA, mais d'obtenir un plan honnête et réalisable pour compléter vos preuves.

### Exemple 3 : utiliser la même expérience pour postuler à plusieurs postes

Ne mélangez pas les mots-clés produit, opérations et croissance dans un CV fourre-tout. Établissez d'abord une base commune de faits, puis générez des versions distinctes :

```text
À partir de la même base de faits réels, génère deux versions distinctes pour « opérations produit » et « croissance utilisateurs ».

Base de faits :
- À l'association du campus, j'étais en charge de l'optimisation du processus d'inscription aux événements ;
- J'ai interviewé 15 inscrits et identifié 4 problèmes récurrents ;
- Avec un camarade en design, nous avons modifié le formulaire d'inscription et les messages de rappel ;
- Le nombre d'inscrits est passé de 86 à 124 par rapport à l'édition précédente ;
- Je ne peux pas confirmer que la croissance est entièrement due à la refonte du formulaire.

Poste A : opérations produit — JD : [collez le JD]
Poste B : croissance utilisateurs — JD : [collez le JD]

Commence par un tableau de correspondance des preuves et de comparaison des versions pour les deux postes, puis rédige séparément les bullets de chaque CV.
N'attribue pas tous les résultats d'équipe à ma seule personne ; utilise des formulations prudentes pour les données dont la causalité ne peut pas être confirmée.
```

Une fois le contenu confirmé, ajoutez « génère un PDF A4 d'une page en style Modern Minimal, et vérifie les débordements de contenu, les pages blanches et les espaces réservés » pour passer à l'étape de mise en page et d'export.

## ⚠️ Points importants à retenir

- ✅ **Aucune invention** : il n'invente jamais de diplômes, d'entreprises, d'expériences de projet, de données ou de récompenses
- ✅ **Demander avant d'écrire** : tout ce qui n'est pas prouvé vous est d'abord demandé, jamais inscrit directement dans le CV
- ✅ **Pensé pour les RH** : l'objectif est que les RH voient d'un coup d'œil votre adéquation au poste, plutôt que d'empiler des mots-clés
- ✅ **L'honnêteté avant tout** : votre CV tiendra toujours la route face aux questions en entretien
