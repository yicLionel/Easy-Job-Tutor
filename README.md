## 🎯 它到底能帮你做什么？

### 1️⃣ 读懂招聘要求（JD 分析）
粘贴一个岗位描述进去，它能帮你拆解出：
- 这个岗位**到底要你干什么**（不只是字面意思）
- **硬技能**（必须会的技术/工具）和**软技能**（沟通、团队协作…）
- **隐性条件**——JD 没明说但 HR 心里有数的要求

### 2️⃣ 拿你的经历跟岗位匹配（差距诊断）
把你的简历发给它，它会逐条对比：
- ✅ **强证据**：你的经历正好对上这个要求
- ⚠️ **弱证据**：沾边但写得不够出彩
- ❌ **缺口**：这个要求你确实还没素材，需要补充什么

### 3️⃣ 追问你没想起来的关键素材
不会直接编造你从没做过的事，而是问你一些很具体的问题，比如：
> "你说你在社团做过宣传，具体用了什么工具？做了多少场活动？覆盖了多少人？"
> "这个课程项目的 final score 是多少？和谁合作完成的？"

有了这些细节，你的简历才有说服力。

### 4️⃣ 重写简历内容（bullet 优化）
把你原来干巴巴的描述（比如"负责公众号运营"）改成：
> 📝 **"独立运营学院官方公众号，6 个月产出 40+ 篇推文，最高单篇阅读量 3.2 万，关注数增长 1200 人。"**

### 5️⃣ 帮你写求职信、申请邮件、内推私信
- 🎯 **Cover Letter**（求职信）
- 📧 **申请邮件**（投递用）
- 💬 **LinkedIn / 微信私信**（找人内推时用）

### 6️⃣ 准备面试
把简历里每一条内容转成**面试官可能会问的问题 + 你应该怎么回答的提纲**，让你面试时不慌。

### 7️⃣ 生成漂亮的简历 PDF（可选）
如果你要最终版，它可以把优化好的内容排版成一份**专业、清晰、HR 看着舒服**的 PDF 简历。支持三种风格：

| 风格 | 适合哪些岗位 |
| :--- | :--- |
| `Classic Professional` | 金融、咨询、法律、政府、国企、教育、会计、审计 |
| `Modern Minimal` | **默认风格**——科技、数据、AI、产品、互联网、创业公司 |
| `Creative Clean` | 市场、内容、媒体、品牌、设计、新媒体运营 |

## 🔧 安装到你的 AI（只需三步）

你需要一个支持 Skill 的 AI 助手（比如 Claude Code、Codex CLI、OpenCode 或 Hermes Agent），然后把 Easy-Job-Tutor 装进去。

> 🖥️ **如果你不懂命令行（终端），可以把这些步骤复制给你的程序员朋友，或者在 AI 工具里问"怎么安装 Easy-Job-Tutor"——AI 会一步一步教你的。**

### 第一步：下载这个项目

打开电脑的**终端**（Terminal / 命令提示符），粘贴下面的命令：

```bash
git clone https://github.com/yicLionel/Easy-Job-Tutor.git
cd Easy-Job-Tutor
```

### 第二步：安装依赖（让 PDF 导出功能正常工作）

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m playwright install chromium
```

> 🔔 如果这一步报错，不要慌——**这个 Skill 的核心功能（JD 分析、简历优化、面试准备）不需要这一步也能用**。PDF 导出是额外的排版工具，暂时用不上也不影响你优化简历。

### 第三步：安装到你的 AI 工具

先回到上一级目录：

```bash
cd ..
```

然后**只执行你正在使用的 AI 工具对应的一段命令**：

```bash
# Codex CLI
mkdir -p ~/.codex/skills
cp -R Easy-Job-Tutor ~/.codex/skills/easy-job-tutor
```

```bash
# Claude Code
mkdir -p ~/.claude/skills
cp -R Easy-Job-Tutor ~/.claude/skills/easy-job-tutor
```

```bash
# OpenCode
mkdir -p ~/.config/opencode/skills
cp -R Easy-Job-Tutor ~/.config/opencode/skills/easy-job-tutor
```

**👉 如果你用 Hermes Agent：**
```bash
mkdir -p ~/.hermes/skills/software-development
cp -R Easy-Job-Tutor ~/.hermes/skills/software-development/easy-job-tutor
```

> 安装完成后，你的 AI 助手就学会这项技能了！

## 🚀 快速开始

### 怎么用？—— 跟你的 AI 这样说就行：

把你要投的**岗位描述（JD）** 和你的**现有简历**发给 AI，然后直接说：

> **"请用 Easy-Job-Tutor 帮我分析这个岗位，然后优化我的中文简历。不要编造经历，缺了什么关键信息先问我。"**

AI 就会一步步帮你做完全流程：
1. ✅ 先分析岗位要求
2. ✅ 再对照你的经历诊断差距
3. ✅ 追问你缺少的关键信息
4. ✅ 重写你的简历内容
5. ✅ （可选）帮你生成 PDF

### 想只看某一部分，也可以这样说：

| 你想做什么 | 对 AI 这样说 |
| :--- | :--- |
| 只分析岗位 | "帮我用 Easy-Job-Tutor 分析这个 JD，告诉我这个岗位到底看重什么" |
| 只改简历 | "参考这个 JD，帮我把简历上的工作经历改得更专业" |
| 写 Cover Letter | "帮我把这个岗位写一封求职信" |
| 准备面试 | "根据优化后的简历，帮我准备面试可能会问的问题" |
| 生成 PDF | "帮我把简历生成 PDF，用 Modern Minimal 风格" |

## ⚠️ 重要提醒

- ✅ **不编造**：不会帮你编造学历、公司、项目经历、数据或奖项
- ✅ **先追问再写**：没有证据的内容会先问你，不会直接写进简历
- ✅ **为 HR 设计**：优先让 HR 能一眼看出你的匹配度，而不是堆砌关键词
- ✅ **诚实第一**：你的简历在面试中一定能经得起追问
