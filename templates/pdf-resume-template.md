# PDF Resume Template

## Purpose

Structure optimized resume content before turning it into an ATS-friendly PDF.

## Default Style

Use `Modern Minimal` unless the user specifies another style or the target industry clearly suggests another style.

## Page Length

- Students / interns / fresh graduates: prefer 1 page.
- Early-career professionals: prefer 1 page; allow 2 pages if necessary.
- Experienced professionals: allow 2 pages when content justifies it.

## Design Rules

- Use clear section headings.
- Keep line spacing consistent.
- Use bullet points for experience and projects.
- Avoid dense paragraphs.
- Avoid excessive bolding.
- Avoid icons, charts, photos by default, or heavy graphics.
- Keep margins balanced.
- Make the resume readable both on screen and when printed.
- Prioritize ATS compatibility over decoration.
- Treat PDF delivery as a screen-to-PDF resume page, inspired by the VibeResume style: one clear page canvas, strong header block, compact contact chips, section divider lines, timeline-like entries, and a light skills panel.
- Keep the visual layer separate from JD strategy. The PDF should display already-optimized, truthful content; it should not add claims, metrics, or keywords that were not approved during resume optimization.
- Use subtle accent color and shallow panels only for hierarchy. Do not turn the resume into an illustrated portfolio page.
- Preserve selectable text. Do not export the whole resume as a screenshot or image.

## Final Quality Check

- No fabricated information.
- No unsupported metrics.
- No spelling or grammar errors.
- No clipped text.
- No overlapping elements.
- Consistent dates and formatting.
- Consistent tense.
- Clear visual hierarchy.
- Suitable length for the candidate level.
- Browser preview and PDF export should visually match closely.
