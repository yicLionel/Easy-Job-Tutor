# Resume Optimization Template

## Source of Truth
List only facts provided by the user.

## Target Positioning
Write 1-2 sentences explaining the candidate's honest fit for the target role.

## Bullet Rewrite Rule
Prefer this structure:

```text
Action verb + task + method/tool + measurable result or business impact
```

If no metric is provided, improve specificity without inventing a number.
