# Learning Path & Interview Prep Template

Use this template when the user asks to 查漏补缺 with a学习路线 / 面试辅导, typically after a
complete analysis (JD + resume) has produced a sorted gap list. It turns the gap list into a
phased action plan and a STAR interview drill.

Input: target `role` + the gap list from `role-knowledge-base.md` (each item = skill + dimension
+ `importance` 1–5 + a `learn` action + a `resource`).

## 1. Route gaps into phases（按重要度分阶段）

| importance | 阶段 | 时间估算 |
| :--- | :--- | :--- |
| 1–2 | 阶段一 · 基础夯实 | 3–5 天 ~ 1–2 周 |
| 3 | 阶段二 · 核心突破 | 2–4 周 |
| 4–5 | 阶段三 · 高阶实战 | 1–3 个月 |

- 同一阶段内按 `importance` 降序排列。
- 固定阶段顺序：基础夯实 → 核心突破 → 高阶实战。
- 无论是否有 gap，最后都补一个「阶段四 · 作品集与复盘」：把学到的能力整合成 1 个可演示项目，
  写好 README 与复盘（示例：AI 小工具 / 运营复盘 / 产品方案），用它作为面试作品集与证据。

## 2. Summary（总览一句话）

- 有 gap：先点名要优先补齐的 top-3 能力，再说明共分几个阶段、每完成一个阶段建议沉淀一个小作品。
- 无 gap：认可高匹配度，建议继续做 1 个代表性项目并准备作品集，再冲击面试。

## 3. Per-skill action（每项差距的动作）

对每个 gap 给出：
- `skill`、`dim`、`importance`
- `action`：具体的「learn」动作（自己用什么方法/工具练到什么程度）
- `estimate`：依据 `importance` 的阶段估算
- `resource`：精选学习资源链接

## 4. Interview prep（面试追问，STAR）

### 通用问题
结合 target role 给出 3–6 条通用面试题（岗位是什么、回忆 3 分钟讲一个代表作、常见方法论、
开放性设计题、项目复盘题等）。

### 针对性追问
按 gap 的 `importance` 递补优先级生成，最大约 5 条，每条用 STAR 法则准备一个**真实案例**：

| importance | 语气 |
| :--- | :--- |
| 4–5 | 请重点准备 |
| 3 | 建议准备 |
| 1–2 | 可补充了解 |

示例句式：

> 面试官可能会问你在「需求分析」上的实践经验，请用 STAR 法则准备一个具体案例。

### 交互原则
- 面试题只针对与目标岗位相关的差距和已确认经历；**不围绕模型臆测的事实编造问题**。
- 每条回答都应有「背景 / 任务 / 动作 / 结果」，结果尽量可量化；无法量化的用「约/近/超过/区间」。

## 5. Output options

提供的输出可选一项或多项：分阶段学习路线（按上文）、通用 + 针对性面试题（STAR 提纲）、
以及可选的一键导出为 Markdown 学习/面试方案文档。
